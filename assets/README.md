# Assets

Institution crests for the Education tab are looked up here:

- `edu-bordeaux.png` — Université de Bordeaux logo
- `edu-msu.png` — The Maharaja Sayajirao University of Baroda logo

Drop the official logo files in with these exact names (square, transparent or
light background works best) and they appear automatically. Until then the site
shows styled monogram crests, so nothing breaks if the files are absent.
